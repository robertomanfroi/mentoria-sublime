## User Story

Como **operadora da Mentoria Sublime (Suellen)**,
quero que o Zoom envie automaticamente um webhook para o N8N quando uma reunião terminar com transcrição disponível,
para que o pipeline de resumo seja disparado sem nenhuma ação manual.

---

## Contexto

O trigger de todo o pipeline é o evento `recording.completed` do Zoom. Para que funcione, é necessário criar um App Server-to-Server OAuth no Zoom Marketplace com as permissões corretas e configurar o webhook apontando para o endpoint N8N.

Referência de arquitetura: `docs/architecture-design.md` — Seção 3 (Fase 1 — Ingesta) e Seção 4 (Segurança — Zoom Webhook).

---

## Critérios de Aceite

- [ ] AC-01: App criado no Zoom Marketplace como tipo "Server-to-Server OAuth"
- [ ] AC-02: Scopes ativados: `recording:read:admin` e `recording:read`
- [ ] AC-03: Event Subscription configurada com evento `recording.completed`
- [ ] AC-04: Webhook URL configurada: `https://n8n.suellenwarmling.com.br/webhook/zoom-mentoria`
- [ ] AC-05: App ativado (status "Published" ou "Activated" no Marketplace)
- [ ] AC-06: Transcrição automática ativada nas configurações da conta Zoom (Settings → Recording → Cloud recording → Audio transcript)
- [ ] AC-07: Quatro credenciais anotadas: Account ID, Client ID, Client Secret, Secret Token

---

## Passos de Implementação

1. Acessar https://marketplace.zoom.us/ com conta da Suellen
2. Develop → Build App → Server-to-Server OAuth
3. Preencher nome do app (ex: `Mentoria Sublime Automation`)
4. Em "Scopes" adicionar: `recording:read:admin` + `recording:read`
5. Em "Event Subscriptions" → Add new event → `recording.completed`
6. Configurar URL do webhook: `https://n8n.suellenwarmling.com.br/webhook/zoom-mentoria`
7. Ativar o app
8. Acessar configurações da conta Zoom → Gravação → ativar "Transcrição de áudio"
9. Registrar os 4 valores para uso na Story 1.4:
   - `ZOOM_ACCOUNT_ID`
   - Zoom Client ID (para credencial Basic Auth do N8N — Story 1.4)
   - Zoom Client Secret (para credencial Basic Auth do N8N — Story 1.4)
   - `ZOOM_WEBHOOK_SECRET_TOKEN`

## Notas Técnicas

- O webhook URL não pode ser testado até o N8N estar rodando com o workflow ativo (Story 1.5)
- O Zoom faz um handshake de validação na primeira configuração: envia `event: endpoint.url_validation` e espera resposta com HMAC SHA256 — o workflow N8N já trata isso no nó "Valida URL Zoom"
- Sem a transcrição automática ativada no Zoom, o payload `recording.completed` não terá arquivo VTT e o workflow seguirá o caminho de "sem transcrição"
