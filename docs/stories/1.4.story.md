## User Story

Como **operadora da Mentoria Sublime (Suellen)**,
quero que todas as credenciais e variáveis de ambiente estejam configuradas no N8N antes da importação do workflow,
para que o workflow funcione sem nenhum segredo hardcoded no arquivo JSON.

---

## Contexto

O workflow `n8n-workflow-mentoria.json` usa variáveis de ambiente para todas as credenciais sensíveis. O N8N também precisa de 4 credenciais OAuth2/Basic Auth configuradas nos seus sistemas internos. Nenhum segredo pode estar no arquivo JSON exportado.

Referência de arquitetura: `docs/architecture-design.md` — Seção 4 (Segurança) e `SETUP-WORKFLOW.md` — Passos 3 e 4.

## Passos de Implementação

1. Acessar https://n8n.suellenwarmling.com.br → Settings → Credentials

2. Criar credencial Zoom:
   - "+ Add Credential" → "HTTP Basic Auth"
   - Name: `Zoom Client ID e Secret`
   - User: [Client ID da Story 1.2]
   - Password: [Client Secret da Story 1.2]
   - Save

3. Criar credencial Google Drive:
   - "+ Add Credential" → "Google Drive OAuth2 API"
   - Name: `Google Drive OAuth2`
   - Seguir fluxo OAuth2 → autenticar com conta Google da Suellen
   - Save (verificar status "Connected")

4. Criar credencial Google Docs (SEPARADA):
   - "+ Add Credential" → "Google Docs OAuth2 API"
   - Name: `Google Docs OAuth2`
   - Seguir fluxo OAuth2 → autenticar com a MESMA conta Google da Suellen
   - Save (verificar status "Connected")

5. Acessar Settings → Environment Variables e adicionar as 8 variáveis:
   ```
   ZOOM_ACCOUNT_ID = [valor Story 1.2]
   ZOOM_WEBHOOK_SECRET_TOKEN = [valor Story 1.2]
   ANTHROPIC_API_KEY = [valor de /home/roberto/.env]
   GOOGLE_DRIVE_TEMPLATE_DOC_ID = 1T7MokSocyjAOcJGscYT1GihGAAzmJ9rZg5BjKNy9e_I
   EVOLUTION_API_URL = [valor Story 1.1]
   EVOLUTION_API_KEY = [valor Story 1.1]
   EVOLUTION_INSTANCE = mentoria-sublime
   WHATSAPP_GROUP_MENTORIA_ID = [valor Story 1.1, ex: 120363XXXXXXXXXX@g.us]
   ```

## Notas Técnicas

- O N8N exige dois registros separados de credencial para Google Drive e Google Docs mesmo sendo a mesma conta — é uma limitação de tipos na plataforma
- A `ANTHROPIC_API_KEY` está disponível em `/home/roberto/.env` — nunca commit esse valor
- As variáveis de ambiente do N8N são referenciadas no workflow como `{{ $env.NOME_VARIAVEL }}`
- Se o N8N estiver rodando em Docker, as env vars podem precisar ser configuradas no `docker-compose.yml` em vez do painel UI
