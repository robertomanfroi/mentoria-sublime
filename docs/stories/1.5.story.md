## User Story

Como **operadora da Mentoria Sublime (Suellen)**,
quero que o workflow N8N esteja importado, com credenciais mapeadas e ativado,
para que o pipeline comece a funcionar automaticamente a partir da próxima reunião Zoom.

## Contexto

O arquivo `n8n-workflow-mentoria.json` contém o workflow completo com 20 nós cobrindo todo o pipeline do webhook Zoom até a notificação WhatsApp. Ele precisa ser importado, ter as credenciais mapeadas nos nós corretos, e ser ativado.

Referência: `n8n-workflow-mentoria.json` (raiz do projeto) + `SETUP-WORKFLOW.md` — Passo 5.

## Passos de Implementação

1. Acessar https://n8n.suellenwarmling.com.br
2. Workflows → Import from file → selecionar `/home/roberto/mentoria-sublime/n8n-workflow-mentoria.json`
3. Abrir o workflow importado
4. N8N solicitará mapeamento de credenciais na primeira abertura:
   - Nós Google Drive → selecionar `Google Drive OAuth2`
   - Nós Google Docs → selecionar `Google Docs OAuth2`
   - Nó de auth Zoom → selecionar `Zoom Client ID e Secret`
5. Verificar nos nós HTTP Request que as expressões `{{ $env.NOME_VAR }}` estão resolvendo (sem fundo vermelho)
6. Clicar em **Activate** (toggle no canto superior direito)
7. Confirmar que o workflow aparece como "Active" na lista de Workflows
8. Testar URL do webhook: `curl https://n8n.suellenwarmling.com.br/webhook/zoom-mentoria`

## Notas Técnicas

- Após importar, verificar se o nó "Zoom Webhook" está como "Webhook" e não como "Webhook Test" — o modo de produção é ativado automaticamente quando o workflow é ativado
- O workflow usa `responseMode: responseNode` — isso significa que o Zoom receberá 200 OK do nó "Responde 200 OK" antes do processamento assíncrono continuar
- Se o N8N pedir para "update credentials" em todos os nós HTTP, verificar se as env vars foram salvas corretamente na Story 1.4 antes de prosseguir
