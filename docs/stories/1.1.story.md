# Story 1.1 — Setup Evolution API no Railway

**Epic:** Automação Resumos Mentoria Sublime
**Agente:** @devops
**Estimativa:** S
**Status:** Draft
**Dependências:** nenhuma

---

## User Story

Como **operadora da Mentoria Sublime (Suellen)**,
quero que exista uma instância da Evolution API rodando no Railway com o número WhatsApp conectado e o bot admin do grupo,
para que as notificações automáticas possam ser enviadas ao grupo após cada sessão.

---

## Contexto

A Evolution API é o gateway WhatsApp do pipeline. Sem ela, as notificações de sucesso e falha não chegam ao grupo. Precisa estar rodando antes da configuração do N8N.

Referência de arquitetura: `docs/architecture-design.md` — Seção 5 (Infraestrutura) e Fase 5 (Notificação).

---

## Critérios de Aceite

- [ ] AC-01: Evolution API deployada no Railway e acessível via URL pública (`https://evolution-xxx.up.railway.app`)
- [ ] AC-02: API Key configurada (substituir padrão `B6D711FCDE4D4FD5936544120E713976` por chave própria)
- [ ] AC-03: Instância `mentoria-sublime` criada no painel manager da Evolution API
- [ ] AC-04: Número WhatsApp da Suellen conectado via QR Code (status: `open` na API)
- [ ] AC-05: Número WhatsApp é administrador do grupo "Mentoria Sublime"
- [ ] AC-06: ID do grupo obtido via `GET /group/fetchAllGroups/{instance}` (formato: `120363XXXXXXXXXX@g.us`)
- [ ] AC-07: Teste de envio manual de mensagem ao grupo via `POST /message/sendText/{instance}` retorna `200 OK`

---

## Passos de Implementação

1. Acessar https://railway.app → New Project → Deploy from GitHub → `EvolutionAPI/evolution-api`
2. Aguardar deploy completar e anotar URL pública
3. Trocar API Key no painel de variáveis do Railway
4. Acessar `{url}/manager` → criar instância `mentoria-sublime`
5. Conectar QR Code com WhatsApp da Suellen
6. Confirmar que o número é admin do grupo Mentoria Sublime
7. Chamar `GET {url}/group/fetchAllGroups/mentoria-sublime` com header `apikey: {key}` para obter o `@g.us` ID do grupo
8. Registrar os valores obtidos para uso na Story 1.4 (env vars do N8N):
   - `EVOLUTION_API_URL`
   - `EVOLUTION_API_KEY`
   - `EVOLUTION_INSTANCE` = `mentoria-sublime`
   - `WHATSAPP_GROUP_MENTORIA_ID`
