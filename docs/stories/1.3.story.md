# Story 1.3 — Preparar Documento Modelo Google Docs com Placeholders

**Epic:** Automação Resumos Mentoria Sublime
**Agente:** @dev
**Estimativa:** S
**Status:** Draft
**Dependências:** nenhuma (paralela a 1.1 e 1.2)

---

## User Story

Como **operadora da Mentoria Sublime (Suellen)**,
quero que exista um documento Google Docs com a identidade visual da Mentoria Sublime e 3 marcadores específicos para o conteúdo dinâmico,
para que o workflow possa gerar resumos com aparência profissional duplicando automaticamente esse modelo.

---

## Contexto

O pipeline gera documentos duplicando um template Google Docs e substituindo placeholders via `batchUpdate` da Docs API. O template original NUNCA deve ser editado pelo pipeline — apenas duplicado. A identidade visual deve estar configurada no template antes da automação ser ativada.

Referência de arquitetura: `docs/architecture-design.md` — Seção 3 (Fase 4) e Seção 6 (Google Doc — Placeholders).

---

## Critérios de Aceite

- [ ] AC-01: Documento Google Docs criado na conta Google da Suellen com identidade visual da Mentoria Sublime (cabeçalho, cores, logo se aplicável)
- [ ] AC-02: Placeholder `{{NOME}}` inserido onde deve aparecer o nome curto da reunião/mentorada principal
- [ ] AC-03: Placeholder `{{DATA}}` inserido onde deve aparecer a data da sessão (ex: "8 de maio de 2026")
- [ ] AC-04: Placeholder `{{CONTEUDO}}` inserido onde deve aparecer o resumo completo gerado pelo Claude
- [ ] AC-05: Os 3 placeholders têm formatação que preserve a identidade visual após a substituição (fonte, tamanho, cor do texto corretos)
- [ ] AC-06: Documento salvo na pasta do Google Drive: `1si0pPBrHXbxUCz6TN1uH-EF39Md5n7Xs`
- [ ] AC-07: ID do documento obtido da URL (`docs.google.com/document/d/{ID}/edit`) e documentado para uso na Story 1.4 como `GOOGLE_DRIVE_TEMPLATE_DOC_ID`
- [ ] AC-08: Documento compartilhado com a conta de serviço Google que será autenticada no N8N (ou permissões de acesso verificadas)

## Passos de Implementação

1. Abrir Google Drive da Suellen → navegar para a pasta `1si0pPBrHXbxUCz6TN1uH-EF39Md5n7Xs`
2. Criar novo Google Docs → aplicar identidade visual da Mentoria Sublime:
   - Inserir logo/cabeçalho visual se existir
   - Definir fonte padrão e esquema de cores
   - Criar estrutura da página (título, seções)
3. No local do nome/título: digitar exatamente `{{NOME}}`
4. No local da data: digitar exatamente `{{DATA}}`
5. No local do conteúdo do resumo: digitar exatamente `{{CONTEUDO}}`
6. Verificar que os 3 textos aparecem exatamente como `{{NOME}}`, `{{DATA}}`, `{{CONTEUDO}}` (sem espaços extras, sem formatação especial que quebre o texto)
7. ID do documento já identificado: `1T7MokSocyjAOcJGscYT1GihGAAzmJ9rZg5BjKNy9e_I`
8. Registrar `GOOGLE_DRIVE_TEMPLATE_DOC_ID = 1T7MokSocyjAOcJGscYT1GihGAAzmJ9rZg5BjKNy9e_I` para Story 1.4

## Notas Técnicas

- Os placeholders devem ser texto puro — evitar criar os `{{` e `}}` com autocomplete ou caracteres especiais do Google Docs que poderiam ser diferentes do texto ASCII normal
- A substituição é feita por `replaceAllText` da Docs API: é case-sensitive e requer correspondência exata
- O placeholder `{{CONTEUDO}}` receberá o texto do Claude com markdown (## headings, bullets) — verificar se a formatação ficará aceitável no doc final (pode precisar de ajuste após teste end-to-end na Story 1.6)
- Se Suellen já tiver um template anterior, pode reaproveitar adicionando apenas os 3 placeholders nos locais corretos
